# 露营卡片（第一阶段）

出处：issue #30（来源提案 #26；用户 2026-11-07 拍板第一阶段：只做卡片生成与下载 / 复制）。

## 做什么

- 左侧面板顶部“生成露营卡片”按钮：玩家点击才生成，不自动弹出；生成后显示预览框，可“下载 PNG”或“复制图片”，也可直接关闭。
- 竖版 720 × 1440 PNG，包含：
  1. 游戏名与日期（上海日历）；
  2. 当前车型：车辆特写截图 + 型号、顶高、三围；
  3. 营地俯视全景截图；
  4. 当日数据：露营者到访数、当日实得金币、爱心车位公益停靠时长；
  5. 里程碑（有才显示）：已拥有侧边帐、连续登录 ≥ 2 天（今天已领时）、爱心车位累计公益停靠。
- 复制：浏览器支持 `ClipboardItem` 与 `navigator.clipboard.write` 时写入 `image/png`；不支持或被拒绝时提示改用下载。

## 不做

不接任何分享渠道，不做回流链接、二维码或统计，不给任何分享奖励。卡片逻辑只读，不入账、不改存档（`tests/card.test.ts` 检查）。

## 数据口径（与界面同源：`src/shared/card.ts` 的 `todayStats`）

| 卡片项 | 来源 | 口径 |
|---|---|---|
| 今日到访露营者 | `camp.daily.arrivals` | 当天（上海日）到达的露营者数，按到达时刻计，含爱心车位 |
| 今日实得金币 | `ledger.today.issued` | 软上限后实际入账（每日礼物 + 收取的停车费），与“每日”区“今日已入账”相同 |
| 爱心车位公益停靠 | `camp.daily.loveMinutes` | 当天离开的爱心车位露营者的整段停靠分钟（按离开时刻计，与累计 `camp.loveMinutes` 同口径） |

- 日界为上海时间 0 点，按有效时间（防时钟回拨）计；统计桶停在更早的日子时当天数据为 0。
- `camp.daily` 是本次新增的存档字段（不升存档版本）：旧存档加载时补为 0、从加载时起计，加载前当天已发生的到访不补算。
- 界面“我的营地车位”区新增一行“今天到访 N 位露营者，爱心车位公益停靠 …”，与卡片读同一个函数。

## 截图

渲染后立即在同一任务里把 WebGL 画布拷进 2D 画布（`scene.ts` `snapshot`），不开 `preserveDrawingBuffer`；随后恢复原尺寸重绘主画面。特写隐藏车位标牌（标牌不做深度测试会挡车）；全景不加雾。
