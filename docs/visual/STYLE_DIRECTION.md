# M2 前的车辆定调选择｜#83 · 待用户拍板

**推荐 B：可信的房车骨架，适度 Q 版的表面。** 从营地上空看，应先看到奶白顶前端的一片深风挡，知道车要往哪儿开；绕近后，才看到机盖的中脊、灯壳如何绕到翼子板、镜臂接在哪里。若想让玩家首先欣赏钣金转折而非整个营地，则选 A。两案的区别不是「像不像某款真车」，而是**在同一副骨架上，把哪些形状画重**。

依据：用户 11-21 的气氛目标见 [STYLE.md](STYLE.md)，11-23 的前脸意见和现有结构检查见 [驾驶体验 §四](../DRIVING_VIEW.md)。[同类调研](STYLE_RESEARCH.md)中的竞品印象均为「据模型知识，待核实」，不是尺寸来源。以下是 #83（2026-11-25）的**提案 / 待核实**，不是生效的评分条款。

## 两案都不能动的东西

- **工程比例**：按 [CLEANROOM_SPEC §三至六](../../CLEANROOM_SPEC.md) 保留各款长宽高（毫米取整零误差）、轴距、前后悬与挂接面。不把车缩短做萌，也不把碰撞盒留在原地而缩放可见模型。轮胎保持正圆，轮心在车轴上、胎底接地，拱顶留出轮廓；镜臂接 A 柱底端，镜面在侧窗可视区、尖端在车宽以内。
- **真车特征是结构词，不是外观模板**：短斜机盖有中脊，接单片后倾大风挡；横扫灯嵌在通到翼子板的壳内，横杠及通用空椭圆环不加字标，下包围有凹进去的进气口与雾灯座；侧窗前梯形、后矩形，尾部为高平尾、上窗、竖灯、下杠。实顶不自带升级件；只有规格所列的眉檐款保留前伸厢体，眉檐窗嵌在本侧窗框内。不以任何真实品牌或车型外观为模板，不逐线描照片，不作原厂精确几何声明。
- **连接不能靠画上去**：侧窗被柱与窗槛围住，内饰在玻璃之后；方向盘经转向柱接仪表台，座椅经底座落在地板上。侧边帐盒贴侧围锚面，展开的篷面要有受力支撑，不穿窗、车顶或地面。涂色可省螺丝，不能代替支架。研究样本和评分参考图均不作资产或生成输入；本提案不引入资产，也不放宽章程的许可证、来源台账和入库核对要求。

## 两个可制作的方向

下表的比例比较用**同款同高度的正侧视图**，不拿透视特写量长度。「头／身」指车鼻至风挡下缘的纵向长度与其后车体长度之比；「轮／车」指轮胎外径与公告车高之比。基准是符合规格的本项目原创车形，而非竞品或某款真车的图。可见色面的夸张量只是打样起点。

| 决策 | A · 写实比例的切面车 | B · 适度 Q 版的营地车（推荐） |
|---|---|---|
| 车头、轮胎夸张多少 | 头／身、轮／车均取同款基准，不作夸张。以机盖折脊和侧围顶部内收的窄折面描述钣金；胎、毂盖、拱边分明，但不加粗轮缘。 | 两项外轮廓比例仍不变。机盖中脊两侧用较宽的受光面，肩角切得更宽、更圆顺，让短鼻在小图里不消失。轮胎不放大，只缩浅色毂盖的可见圆：先试基准直径的 **0.9 倍（提案 / 待核实）**。外径不变时每侧多出原毂盖直径的 `(1−0.9)/2 = 0.05` 作深胎色；这是视觉厚度，不是改轴高、轮径或轮拱。 |
| 几何做到哪 | **5 网格 / ≤2,472 面**。面优先留给机盖脊、收肩、分层进气口、灯壳转角和窗框。贴近侧面时看得到玻璃在框内、格栅横条在唇面之后。门缝、浅性格线用窄色带，不刻漆面纹理、胎纹或格栅网眼。 | **同为 5 网格 / ≤2,472 面**。把视觉重点从连续的小倒角移到几块大肩面、圆拱和胎侧；灯与进气口仍有壳、凹底及横条，不退回平脸。窗带保留窗柱与门的分界；缝线、轮毂纹、灯内分区只在既有表面分色，不堆零件。预算不够先减非承重的装饰折面，不删镜臂或驾驶室连接件。 |
| 配色、光照怎么分工 | 雾蓝下身、奶白上身；缩小车漆与饰件的明度跳变，靠现有暖侧逆光扫过窄面，读出板件前后层次。深玻璃与深裙边之间留车身色；不追求镜面镀铬或照片纹理。 | 同一组雾蓝与奶白，深窗带与亮顶的分界更干净；把大块中明度蓝留给侧墙，不用密拉花填空。金麦地、暖棕路、粉色切面云作暖背景，阴影留冷紫／暖棕。车静止熄灯时仍须能从斜盖、风挡分出前后，不靠纯黑描边。 |
| 与规格共存的底线／代价 | **保关系，不追牌相**：看出「横灯 → 横杠 → 下进气口」的层次即可，不再抠可识别的品牌脸。优点是近景容易解释结构；风险是缩到竖屏后，细转折全挤在同一条暗线里。 | **放大层次，不放大零件边界**：横灯不是圆眼睛，轮子不外凸，宽肩不能吃掉侧帐的平安装面。优点是远看仍有斜头与直尾；风险是明暗反差太大，窗带像贴纸、轮胎像黑饼。要靠嵌框、浅毂和拱内空隙把深度读回来。 |

**为什么偏向 B（设计判断，待核实）**：调研里，Pocket Camp 的门窗让人先读到「能住」，PAKO 的俯视车则靠机盖与窗块的错位辨向。这两件事与我们的停驻、驾驶都有关，但都不要求夸张轴距。B 把稀缺的轮廓与明度差用在这两处，同时留下 A 最值得保的风挡、前灯与进气口结构。若选车特写才是第一体验，而营地里主要靠 UI 找车，A 的窄折面更有价值。不推荐进一步做成大头大轮玩具车：同一轮心放大轮胎会穿地，抬轮心或重切轮拱又牵动车轴、侧窗下沿和饰件。

## 对 M2–M5 的影响（制作提案，不重排 #68 的里程碑）

| 检查节点 | 选 A 的工作重点 | 选 B 的工作重点 |
|---|---|---|
| M2：先在原创样车上定标 | 前斜视看折脊、横灯与下唇的进深，再退到营地机位看前后是否仍可分。若远看失败，先调整玻璃明度，不加细线。 | 同车同光试宽肩面与毂盖减幅；先在竖屏认车头，再绕到侧面看轮拱空隙。若出现黑饼，退回基准毂盖，不放大轮胎。 |
| M3：检查规则能否推广 | 随该阶段内容核对高低顶及眉檐款，重点是窄折面在不同高度下是否吞窗、挡镜。预计需逐款调转折。 | 用同一套亮顶／深窗／蓝侧墙规则对照高低顶。眉檐的投影与窗框必须能区分，不能为统一圆润感给其他车也加眉檐。 |
| M4：车与配套物同框 | 装备座与支杆按车体的分层语言表现；若细杆在暖雾里消失，先改明度，不画浮空高光。核对展开／收起与车侧关系。 | 营具也用大面，但篷布与伸臂不能并成一片。帐下仍应读到车门、轮胎和支撑方向；营地道具不与玩家车争用同一大片雾蓝。 |
| M5：看累计成本与退步 | 在营地群车、行驶和手机竖屏里复看细转折是否闪烁；若超预算先舍装饰细面，保留结构深度。 | 同样复看群车，尤其检查逆光时亮顶是否融进麦地、大暗窗是否糊成黑块；优先调相邻色块，不靠新增网格或描边通道补救。 |

**怎么验证取舍**：用户选定后，由主设在后续里程碑提供本项目同款、同光、同距离的基准与样车对照。先遮住 UI 文字，让用户指认静止车头及侧帐所在侧；再用前斜、正侧、后斜与眉檐高机位对照，沿镜臂、窗框、座椅和篷架逐一追到支撑处，看有无穿出、悬空或共面闪烁。实现时逐款过尺寸、锚点、灯具、眉檐及面数回归，整场过上述 E2E 预算。小屏辨向与真实设备表现尚无实测，不能以效果图或单车预算代替。

## 请用户拍板（M2 前）

1. **主方向选 A 还是 B？** 推荐 B；两者都不采用真实品牌脸，也不动公告三围与锚点。
