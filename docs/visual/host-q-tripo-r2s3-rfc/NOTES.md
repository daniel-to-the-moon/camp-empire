本轮是帽子结构改造，不是把 r2s2 的环绕后沿往头发上贴，也不是细雕身体。造型未过关，需要再复审。未绑骨、未跑 Tripo、未合并任何 PR。

## 改了什么

按 #117 口径与 B 三视图，把环绕后沿的 r2s2 帽重建为「正戴鸭舌帽 / 棒球帽」：

- 只有额前一片有厚度的帽舌（visor / bill），略向下弯
- 两侧帽口收贴帽身，不再向两侧翻出一圈檐
- 后面只留靠头的梯形开口、一条调节带和一颗小带扣，不做环绕帽檐
- 侧视去掉脑后那段翘出的边；侧面只在前方伸出帽舌，背后没有外翻投影

帽冠拓扑是新建的低模外壳（外+内薄壳 + 实心顶扣 + 实心帽舌 + 调节带），不是在原 AI 三角网上把后沿往里贴。保留米色顶点色、可见顶扣、帽舌厚度。身体、发型、头身比和服装未改。帽节点平移保持为原佩戴位，没有为新结构做位移微调，也没有把平移烘进顶点。

- 正面：相机在 −Y，看向原点
- 侧面：相机在 +X（角色右面，面孔朝画面右）

## 质检

按 blender-2 skill，用 `qa_check.py --profile game --no-uv`。项目用顶点色、无 UV，所以跳过 UV，并在此注明原因。没有把 `mesh_stats.py --budget web` 当成 3000 预算。

`HostCap`：非流形 0，退化面 0，线框边 0，未应用缩放（已是 1,1,1），法线一致。留下 **12 条边界边**（开口两侧各一个 6 边小洞）。自动补面会在该处引入 3 面共边，因此保留小洞并记录。3 个网格岛：帽壳、独立闭合顶扣、调节带+带扣。QA 把顶扣/整顶帽判为 floating，是因为该检查按「落在地面的道具」写的；佩戴帽在约 1.14 m 处「浮空」是预期，不是掉件。HostCap 有 16 对共面重叠三角，多半在顶扣与帽顶的接触带，未清干净。

`HostBody` 的 QA 问题（1 条非流形边、14 个 n-gon、1 条法线不一致、眼部等小岛、240 条边界边）是 r2s2 既有状态，本轮未改身体，故原样接受。

## 还存在的问题（如实，未过造型关）

1. 本轮只解决帽子结构，不宣称造型过关，需要再复审。
2. 调节带和带扣的几何是有的，但在背面和正后下方几乎看不清：内腔较暗，而且后发会挡住带子。不如 B 图的后开口清楚。
3. 帽舌仍偏平板，弯度不如 B 图。
4. 前发（尤其右前一绺）从帽冠/帽舌穿出。按任务要求不能改发型来填缝或避穿。
5. 开口腿部两侧各留一个 6 边小洞（12 条边界边），斜下仰视时可能在开口侧壁看到缝。
6. 顶扣与帽冠有少量共面重叠（QA 记 16 对）。
7. 新帽冠是较规整的切面穹顶，和 r2s2 那顶不规则黏土帽不同，块面感也比 B 图更硬。
8. 身帽相交从 111 对增到 195 对；部分角度仍可能看到头发穿出帽壳。
9. 预览光照是新建的，帽色在背光处偏灰，不要把它当成材质最终观感。
