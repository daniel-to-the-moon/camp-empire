# Host Q r2s2 · Blender 细雕与回读记录

基线为草稿 PR #113 的 `3074eb94`，已包含已评审的鞋底和鞋带。当前输出来自 Blender 5.3.0。原始 r2 的输入哈希已核对；本轮在 r2s1 高模副本上工作。[上轮交付与评审](https://github.com/daniel-to-the-moon/camp-empire/tree/3074eb94e6978527ae14ffdf690dac3de79fd220/docs/visual/host-q-tripo-r2s1-rfc)

## 造型修改

1. 在高模的 Blender Sculpt 视图遮罩身体，隐藏独立帽，依次从后、侧、正面和后斜下使用 Grab 和 Smooth 笔刷。向两侧展开卷发肩部，柔化发冠硬折，把后枕针尖拉回发团。保存的手工笔刷阶段有 877 个头发顶点移动超过 0.03 mm。随后局部平顺发底，补足后帽沿下的发量，收进帽壳侧面的发根。沿前卷和后枕大绺在现有顶点色上做了轻微棕色明暗过渡。
2. 向下调整下巴及相连面部体积，轻微拓宽下面部，同步调整衣领、肩部及卫衣厚度。半睁眼、眉和唇线的编辑分组保留。脚、短裤、双手与鞋带均按修正前后对应面的顶点坐标和顶点色逐项核对。
3. 游戏版将手修高模的头发局部简化，优先减发底和内层，再分配给冠部和外侧轮廓；游戏版头发由 545 降到 539 三角。身体和帽子分别为 `HostBody` 和 `HostCap`。两份 Blender 文件可继续编辑，三份 GLB 均在新场景重新导入。

## 后帽沿复测

在新场景导入戴帽 GLB，对 r2、r2s1、r2s2 都有有效结果的同一组 371 个后侧位置，以 5 mm 网格测帽沿下表面与头发上表面的垂直距离。遇到相交时，正间隙记为零。另对全身与帽壳做精确三角相交查询，并自上向下检查露出帽顶超过 2 mm 的采样点。

| 指标 | r2s1 | r2s2 |
| --- | ---: | ---: |
| 后侧垂直间隙中位数 | 3.05 mm | 0.00 mm |
| 后侧垂直间隙 P90 | 28.56 mm | 13.24 mm |
| 身帽相交三角对 | 115 | 111 |
| 顶面向下采样，头发顶出帽壳超过 2 mm | 0 | 0 |

垂直距离受表面倾角影响。三角对数量也会随发网格的三角划分变化，复审时请结合图 03 的同机位仰视。

## 仍待确认

- 发冠较圆，偏分与耳侧两个前卷仍在。近看冠部侧面仍有直折，后枕底边还留有少数尖角；与 rfc_06 相比，波浪层次更简化。
- 后帽沿下局部仍有暗缝，且身帽存在相交。发顶采样和 P90 均不能证明其他角度完全没有穿插。
- 图 06 按跟随镜头的 45° 垂直视场、3 m 示例车高在 Blender 里模拟，在手机和桌面视框内分别呈现约 71 和 61 像素高的戴帽角色。此轮完成静态 GLB 回读，实际游戏内的动画和绘制性能另行验收。[游戏镜头参数](https://github.com/daniel-to-the-moon/camp-empire/blob/3074eb94e6978527ae14ffdf690dac3de79fd220/src/shared/camview.ts)
