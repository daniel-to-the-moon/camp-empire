# 画面风格与视觉评分标准

**方向 B：可信骨架 + 适度 Q 版表面。** 从营地上空看，先凭顶高、窗带和涂装认出朋友的车，知道车头朝哪边；走近才看清灯壳怎样绕到翼子板、侧帐怎样支起来。结构对照真车的部件关系，亲和感来自肩面的转折和色块，不来自缩短车身或放大车轮。

依据：用户在 #83 / PR #84（2026-11-25）选定的[车辆方向 B](STYLE_DIRECTION.md)和[体验支柱](../GAME_PILLARS.md)。营地应温和、低压力；《旅行青蛙》只指「放心离开、期待再见」的玩法情绪，**美术完全不参考**。用户 2026-11-21 给出的 `reference.png` 只供评分时参照配色、切面与光照，不复刻物体、车型或构图。资产遵守 [CHARTER §三](../../CHARTER.md) 与 [CLEANROOM_SPEC](../../CLEANROOM_SPEC.md)：参考图、竞品画面、MXGARAGE 旧 GLB 及其截图或渲染图均不得用作资源生成输入。

## 配色（palette）

- 黄昏由灰蓝天空过渡到暖杏色地平线（约 `#7f93c4` → `#f3cfa0`）；金麦色地面（约 `#d9a24a`～`#f0c46a`）、暖棕道路（约 `#8a6450`）、粉色切面云（约 `#f2b3a8`～`#fbe3dc`）构成暖背景。这些是沿用的参考色，用来判断冷暖关系，不逐像素对色。
- 基准车以雾蓝侧墙（约 `#5f8fb0`）配奶白上身，亮顶、深窗带、车漆之间有清楚的明度分界。其他涂装也要留出连贯的大色面，让车从麦地里显出来；不靠高饱和拉花、纯黑描边或亮灯抢眼。

## 造型（shape）

- **保留骨架。** 长宽高、轴距、前后悬与装备挂接面按规格；轮胎正圆、轮心对轴、胎底接地，轮拱与胎侧之间读得出空隙。房车直立的侧墙、平直高尾不是缺点。实顶不自带升顶装备，只有规格中的 SH5043 眉檐款保留前伸厢体。
- **前脸看层次，不看像哪个牌子。** 短斜机盖中脊接单片后倾风挡；横扫灯嵌入通向翼子板的灯壳，横杠与通用空椭圆环在两灯之间，下包围里看得见进气凹口与雾灯座。侧窗前梯形、后矩形，尾部上窗、竖灯、下杠与斜车头有别。不逐线描公告照片，不做品牌脸、字标或原厂精确几何声明。
- **柔和的是表面。** 用几块宽肩面接顺转角，用圆拱、浅毂与深胎侧分出轮子的体积；门缝、灯内分区可用表面分色。低多边形仍看得出面与面的转折。不是把横灯改成圆眼、把进气层次画平，或为显得可爱而做大头大轮。
- **连接必须成立。** 镜臂接 A 柱底端，镜面处于侧窗可视区且不超车宽；玻璃嵌在柱与窗槛之间，内饰在玻璃之后。方向盘经转向柱接仪表台，座椅经底座落到地板；展帐时能从篷布沿伸臂找到贴在侧围的帐盒。沿用用户 2026-11-21 的验收规则：看得见部件悬空、穿模或内饰跑出车身，**造型分不高于 3**。正常遮挡不等于缺支撑，不能因远景看不到转向柱就判它悬空。

## 光照（lighting）

低角度的暖侧逆光照出机盖和肩面，长影柔和，暗部偏冷紫或暖棕，避免死黑与过曝。地平线可有暖雾，但不要让奶白顶融进麦地，或让深窗、车漆与轮胎糊成一块。温和不是模糊。

## 可读性（readability）

先看营地俯瞰与手机竖屏：不读名字牌，静止熄灯的车能否凭斜盖、深风挡与直尾辨向？同屏时能否凭熟悉的顶高、涂装与已装装备找到朋友的车？再看行驶与特写：车与路面分得开；有侧帐时，帐下仍读得出车门、支撑和待客的空地。同款同色可用不挡车的署名辅助，不靠品牌、稀有度或常驻数值气泡认人。标牌清楚不重叠，不用闪警、催促性倒计时制造紧张感，也不把车灯当作车主在线的标志。

## 不退步（regression）

与 main 基线的同机位截图比较：原来能辨的车头、能追到的连接是否还在？留意新出现的穿模、黑块、闪烁、缺件或比例失调。没有基线时只描述当前图中可见的缺陷，不声称发生了版本退步。

## 评分口径

`scripts/devloop/visual-judge.mjs` 将本文件全文交给评分方。用营地、行驶、手机竖屏三张必需图判断整体；有前斜、正侧、后斜特写时用来核对结构。评语指出**哪张图、哪个部件、哪层关系清楚或丢失**；被遮挡或分辨不出的细节记为待核实。不用透视截图量公告三围，也不凭截图推算性能：尺寸与锚点由几何测试核对，整场预算仍以 [budgets.json](../../scripts/e2e/budgets.json) 为准。

五项各 1–10 整数分，沿用 [gates.json](../../scripts/devloop/gates.json) 的提案门槛：每项 ≥ 4、五项平均 ≥ 6，且不退步 ≥ 6。按里程碑看进展：M1 的车不因保留工程比例、不像玩具或未采用试样毂盖尺寸而扣分；M2（#68）的黄昏麦田是氛围目标，不把尚未制作的麦田或真人互访当作 M1 车辆退步。反之，已有结构缺陷不能用「已验收」豁免。定调稿中的打样数值仍是**提案 / 待核实**，不是新阈值。
