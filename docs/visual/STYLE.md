# 画面风格目标（视觉验收的评分依据）

来源：用户 2026-11-21 给出的参考图（缩小后存为 `docs/visual/reference.png`，只作评分时的风格参照）。只借它的配色、造型语言和光照，**不复刻**参考图里的任何具体物体、构图或车型；它不是模型或贴图素材，不得用于生成游戏资源（CLEANROOM_SPEC）。
视觉验收角色（`scripts/devloop/visual-judge.mjs`）把本文件全文和截图一起交给多模态模型评分；改这里就是改评分标准，需用户确认。

## 1. 配色（palette）
- 暖色调、黄昏感：天空从上方的灰蓝（约 `#7f93c4`）过渡到地平线的暖杏色（约 `#f3cfa0`），整体偏暖。
- 地面主色是金黄 / 麦色（约 `#d9a24a`～`#f0c46a`），道路是暖棕（约 `#8a6450`）。
- 点缀：粉色系低多边形云（约 `#f2b3a8`～`#fbe3dc`）；车身用冷色（雾蓝约 `#5f8fb0`）+ 奶白，与暖背景形成对比、一眼能找到。
- 避免：大面积高饱和纯色、灰绿冷调占满画面、纯黑阴影。

## 2. 造型（shape）
- 低多边形（low-poly）、切面清楚、边缘利落；物体轮廓简洁可读，俯瞰时能分辨车头车尾与车型。
- 车辆可爱、圆润比例（切角、轮拱、两段式涂装），不要“方盒子”。
- 不出现品牌标志、真实车型的可识别外观（CLEANROOM_SPEC）。
- **结构要交代清楚**：部件有支撑和连接（方向盘有转向柱、接仪表台；座椅有底座落在地板上；车窗在车身框架内），不出现悬空、穿模、跑到车身外的部件。出现任何一处，造型分不高于 3（用户 2026-11-21 验收时指出“悬空的方向盘、没有仪表台”）。

## 3. 光照（lighting）
- 低角度暖色阳光（日落方向的侧逆光），长而柔和的影子；地平线附近有暖色辉光 / 雾。
- 明暗层次清楚但不过曝；阴影带一点冷紫或暖棕，而不是纯黑。

## 4. 可读性（readability）
- 主体（玩家的车、营地设施）在画面中清晰可辨，不被雾、阴影或界面遮挡。
- 文字标牌清楚、不重叠。

## 5. 不退步（regression）
- 与 main 上一版截图相比：没有出现穿模、黑块、闪烁、缺失物体、比例失调等明显退步。

## 评分说明
每项 1–10 分。是否通过的门槛见 `scripts/devloop/gates.json` 的 `judge`（提案：每项 ≥ 4，总体 ≥ 6，不退步 ≥ 6）。
评分是“比上一版更接近上面的方向、且没退步”，不是要求一次做到和参考图一样：每个里程碑（#68）只负责其中一部分。
