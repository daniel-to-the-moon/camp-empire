## 从哪里改起

在 Blender 5.3.0 中直接打开 SHA256 匹配的 `blender/host_q_tripo_p20_r2_hi.blend`，实读 18 个网格、10,834 个三角面。原始 r2 GLB 单独导入后为 1 个网格、5,604 个顶点、10,834 个三角面。原始高模高度 1.000 m。开工前和最终回读时均复核包内七项 SHA256。

- 在高模副本的 Blender 雕刻视图，用 Grab 和 Smooth 分别处理前额两绺、耳侧、后枕、颈后细尖和鞋跟；通过正面、侧面与背面框选和比例编辑收前额、调整分缝、补后侧佩戴处体积。头发保留一个连续的头发岛。
- 重新利用原有两块眼眉网格，缩短、减薄并调整角度，作为短眉。在实际头部表面按正视图逐点描眼裂与唇形，在 Edit 网格内连接上下缘、眼睑、眼白、虹膜与瞳孔的面。上下缘具有独立顶点和深度。轻微微笑由两条独立唇缘构成，保留原鼻并用 Smooth 收转角。可编辑文件中两侧眼区各有 68 个顶点编为组，唇区有 45 个。眼口附面贴合头表，后续做表情前仍须检查活动边界。
- 在两只原手的掌端横切，保留拇指，分出四个指根，各自分节挤出、收细和内屈，使中指最长、小指最短。低模在离地约 0.428 m 的横截面上，每只手有四个互相分开的长指截环；抬高到约 0.462 m 可分辨拇指与掌体。
- 短裤沿裤脚方向作四道横切，形成两圈白色包边；另切两侧纵向条纹。颜色边界落在实际面边上。鞋跟后部向内收窄，袜口使用切线划分裸腿与白袜，鞋带保留六处原几何。
- 先在临时低模上试算角色基础网格的面数：基础身体试减为 1,774 三角，给脸、指节和边线留出 566 三角。最终从手改高模降面，优先处理发底和颈后、衣背与衣褶内侧、鞋底内侧等处；短裤在简化后的裤片上复用同组手定裁线。眼口附面保留。手工造型用 Blender 原生编辑与雕刻；局部重复编辑、按岛上色、预算检查、导出和回读使用脚本辅助。
- 颜色使用 `host_mat` 和角域顶点色 `albedo`，导出为 `COLOR_0`。头发与眉为棕色，脸和手按肤色隔离，卫衣米色，裤身绿色，双侧纵条与裤脚条纹为暖白，袜鞋偏白。帽色沿用独立件。文件没有 UV、图像纹理、骨架、动画或形态键。

## GLB 回读

使用全新 Blender 5.3.0 场景分别导入三份 GLB，并复核 glTF 节点、顶点属性和材质。下列是 glTF 的世界坐标，单位为米，次序为 (X, Y, Z)。+Y 向上，鼻尖朝 +Z，源文件的 `hand_R` 位于 +X。无帽和戴帽文件中的身体尺寸一致。

| 文件 | 回读网格 / 三角 | 世界 bbox，最小点 → 最大点 |
| --- | --- | --- |
| 无帽 | HostBody / 2,331 | `(-0.283081, 0.000000, -0.226778) → (0.285212, 1.252860, 0.217587)` |
| 单帽 | HostCap / 660 | `(-0.195317, 1.111325, -0.276936) → (0.165974, 1.318737, 0.276623)` |
| 戴帽 | HostBody + HostCap / 2,991 | `(-0.283081, 0.000000, -0.276936) → (0.285212, 1.318737, 0.276623)` |

- 游戏版脚底 Y = 0.000000，无帽发顶 Y = 1.252860，帽顶钮扣 Y = 1.318737。帽顶比 1.320 m 低约 1.26 mm。以脚底为原点整体等比放大身体，系数 1.25206。
- `HostCap` 的 glTF 平移为 `(-0.023680085, 1.136352301, -0.047160354)`，旋转为单位旋转，缩放为 `(1, 1, 1)`。平移仍在节点上。复核 334 个帽子顶点，本地位置与 r2 独立帽件逐点一致；颜色因导出量化，归一化通道最大差约 0.000008。帽沿几何、佩戴位和无字帽面均沿用 r2。

## 仍需造型评审

- 正侧面可以辨认两侧前卷、鬓发与后枕的体积，但后枕下缘仍有零散细尖；裸头顶的转折比 rfc_06 的圆润波浪更硬。近看耳部转折和指尖也还有明显低多边形折面。
- 近侧帽沿已能读出眼眉。对帽子覆盖区域做 5 mm 间距的垂直射线采样，从顶面看，身体超出帽壳超过 2 mm 的样点由 r2 的 630 个降至本版的 0 个。精确三角面相交查询仍有 115 对身体与帽子三角面相交，集中贴合区仍待评审。后帽沿有局部透空间隙；在新旧都覆盖的 371 个后侧样点上，垂直空隙的中位数由 0.6 变为 3.1 mm，第 90 百分位由 44.1 降至 28.6 mm。此测量以两张表面之间的垂直距离估计，不能代表法向缝宽。
- 游戏版用发顶至下巴前表面的距离估算，头身比约 **1:3.75**，高模约 **1:3.69**，较目标 1:3.5 略修长。瞳孔形状、唇线和后帽沿弧度可结合特写继续评审；本轮为静态样件。
