# 转弯与扫掠包络（M1 原型，讨论稿）

> 数字由 `npm run swept:table` 生成（`scripts/swept-table.ts`），改参数后重跑并同步本文。
> 本文是游戏手感参数，**不是工程安全标准**：不含后视镜、外挂件、过渡转向和坡度。

## 一、公式（`src/shared/kinematics.ts`）

单车模型，以后轴中心为参考点：

- 真实外前轮最小半径 R外 = 轴距 L / sin(外轮最大转角 δ)
- 游戏外前轮半径 = k × R外（k < 1：比真车好开）
- 后轴中心最小半径 Rr = √(R外² − L²) − 轮距 / 2
- 满舵扫掠：车身内侧半径 Rr − W/2；车头外角半径 √((Rr + W/2)² + (L + 前悬)²)；扫掠宽 = 二者之差

## 四、为什么自动规划会放大半径

满舵急转时，车头外角半径远大于后轴半径（SH5043：后轴 3.16 m，车头外角 6.45 m），前悬长的房车外角会甩出车道。
实测：大门道路接入环路时，按满舵半径规划的四条 Dubins 路线全部碰到篝火岛或围栏。
因此 `src/shared/parking.ts` 依次尝试 1.05 / 1.5 / 2 / 3 倍最小半径，取第一条不碰撞的路线。
路线只由“≥ 最小半径的圆弧 + 直线”组成，所以**系统能开出来的路线，玩家用同一套操控也能开出来**。

## 五、自动化验证（`tests/camp.test.ts`）

- 25 个变体 × 5 个车位（其他车位停着最大车）：NPC 进场、NPC 离场、玩家从出生点一键泊入、倒出，全部规划成功且全程不碰撞。
- 一键泊回家位：在环路上随机取起点（横向偏移 ±1.2 m、朝向偏 ±46°，15% 掉头），**顺行起点 100% 成功**；
  车头与单行方向相反时（夹角 > 107°）给出“请先掉头”的明确提示——5.6 m 车道内只往前开的路线掉不了头。
