这台设备

真机复测

  1. 目标机器是盛俊的 MacBook（型号待核实）和 Google Pixel 6。在那台机器自己的浏览器里打开本页 /perf.html。不要打开营地首页，也不要开 Chrome 的设备模拟。
  2. 开发服务器：npm run dev -- --host。电脑打开终端里的地址，把路径换成 /perf.html。手机用同一局域网里的主机地址。
  3. 地址保持默认（SH5043 占位车，阴影开，无侧边帐）。看上面「抄这三行」：运行时三角面、运行时 draw call、加载体积。
  4. 同时抄「这台设备」里的 UA、布局视口、devicePixelRatio、WebGL 渲染器。MacBook 从「关于本机」抄型号。Pixel 6 在系统设置里确认型号是 Pixel 6。
  5. 云端表格里的真机列保持「待核实」。headless 和设备模拟的数字不能填进真机列。
